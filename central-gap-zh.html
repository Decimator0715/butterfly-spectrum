偶分母中央能隙为何闭合

模型与结论

采用最近邻方格 Harper 方程，晶格常数和横向跃迁归一化为1：

un+1 + un−1 + 2λcos⁡ (2𝜋𝑝𝑛 q + ky) un = Eun.
un+q = e𝑖𝑞kx un,gcd ⁡ (p,q) = 1,q = 2L.

λ 为实数，λ = 1 对应各向同性。由于 p/q 已约分且 q 为偶数，p 必为奇数。在完整二维磁布里渊区内，第 L 与 L + 1 条能带在零能接触，中央全局能隙严格为零。

构造两个严格零能态

选 ky = π/2，在位势满足

vn = −2λsin⁡ (2𝜋𝑝𝑛 q ),v0 = vL = 0,vq−n = −vn.

在 E = 0 定义转移矩阵

A(v) = ( −v −1 1 0 ),J = A(0).
( un+1 un ) = A(vn) ( un un−1 ) .

直接乘法给出

det ⁡ A(v) = 1,J2 = −I,A(−v) = −𝐽𝐴(v)−1J−1.

记 B = A(vL−1)⋯A(v1) ，L = 1 时取 B = I。完整磁周期的转移矩阵为

Mq = A(vq−1)⋯A(vL+1)𝐽𝐵𝐽.

由于相反的势按逆序出现，

A(vq−1)⋯A(vL+1) = (−1)L−1JB−1J−1.
Mq = (−1)L−1JB−1J−1𝐽𝐵𝐽 = (−1)LI.

该恒等式对任意 L 和实 λ 精确成立，无需弱耦合展开。选 Bloch 相位满足

e𝑖𝑞kx = (−1)L.

即 L 为偶数时 kx = 0，L 为奇数时 kx = π/q，均模 2π/q。此时任意两维初值都满足 Bloch 边界条件。最近邻递推由两个初值唯一决定，因此有限 Bloch 哈密顿量的零空间恰为二维。q = 2 时，两条邻接路径必须相加，不能相互覆盖。

确认中央两带与全局隙

定义半周期平移与交错变号：

(TLu)n = un+L,(𝐷𝑢)n = (−1)nu n,S = DTL.

q 为偶数保证两个操作保持同一 Bloch 边界条件。p 为奇数给出 vn+L = − vn ；半周期平移翻转在位势，交错变号翻转跃迁。因此同一动量处

𝑆𝐻S−1 = −H.

能量成 ±E 配对。接触点恰有两个零能态，剩下的态分为 L − 1 个负能态和 L − 1 个正能态，所以两零能态恰为 EL 与 EL+1 。

EL(𝐤) ≤ 0 ≤ EL+1(𝐤).

接触点使两边界同时取零：

max ⁡ 𝐤EL = 0 = min ⁡ 𝐤EL+1.
ΔL = min ⁡ 𝐤EL+1 − max ⁡ 𝐤EL = 0.

仅有能量反射对称不能证明闭隙；双重零能解是不可缺少的另一步。

能隙候选标签

带数 r 与整数 m 的候选关系为

r ≡ 𝑝𝑚(𝑚𝑜𝑑q),pq 2 ≡ q 2(modq).

因此 m = q/2 对应中央带数 r = q/2。这只是候选标签的对应；中央隙已经闭合时，不能给由该隙隔开的占据子空间赋予一个已定义的陈数。

动量空间约定中的两条路径

本节采用项目约定，区别于前面的实空间归一化：

Kn = kx + nG2,G1 = 2π,G2 = 2𝜋𝛼.
𝜀n = −2t1 cos⁡(kx + 2𝜋𝛼𝑛),h = −t2.
H0,q−1 = he−𝑖𝜃,𝜃 = qk y.

既约 p/q 对应 q 个独立动量态。0 的 Bragg 伙伴为 −m；当 q = 2m 时，+m 与 −m 模 q 是同一个态，并非两个独立伙伴。q = 2 时两条邻接贡献必须求和。

取正整数 m 且 q = 2m。由于 p 为奇数，选 g = (1−p)/2，正 Bragg 面为

kx = π(𝑚𝛼 + g) = π 2 , kx G1 = 1 4.
𝜀0 = 𝜀m = 0,𝜀−j = −𝜀j.

路径 0 → 1 → ··· → m 和 0 → −1 → ··· → −m ≡ m 都有 m 步。若 m 小于 q/2，两条弧分别长 m 和 q − m；在中央 Bragg 面，两条同阶通道都不能丢掉。

干涉：微扰表达与精确消元

在中间分母不为零的条件下，最低阶振幅为

V +(m) = hm ∏ j=1m−1(−𝜀j).
V −(m) = (−1)m−1e−𝑖𝜃V +(m).

相消条件为 e−𝑖𝜃 = (−1)m 。项目所用 ky = kx 切片在 kx = π/2 处满足此条件。

对于 m ≥ 2 的精确论证，保留 0、m 两态，消去两段长度为 m − 1 的补空间链。按正向和反向路径排序，两链哈密顿量满足

H− = −DH+D,G± = (0 − H±)−1,G − = −DG+D.

这里 D 是补空间链上的交错对角矩阵，逆矩阵公式要求补空间在零能可逆。对角自能相消，端到端 Green 函数满足

Σ0(0) = Σm(0) = 0,(G−)1,m−1 = (−1)m−1(G +)1,m−1.

精确 Schur 非对角元为

V eff(0) = Am [1 + (−1)m−1e−𝑖𝜃] ,A m = hm det ⁡ (−H+).

在相消相位，整个二阶有效块为零，两零能态保留。若补空间奇异，不能直接使用逆矩阵公式。固定非零 t1 ，其行列式是 t2 的多项式且在 t2 = 0 非零，因此奇异值为孤立点，本征值结论可由连续性延拓。前面的转移矩阵证明不依赖此逆矩阵。

当 m = 1、q = 2 时，没有中间链：

V eff = h(1 + e−𝑖𝜃),𝜃 = π.

两项直接相消。

对选带方法的含义

选带规则不能创造或消除本征谱隙。简并处本征矢可在子空间内旋转，单列数值本征矢的中心权重并不唯一。应保留简并子空间及共同能量，不能仅凭分数相同或 NaN 判断闭隙。

相消发生在特定 ky ，并非任意固定切片都闭合。例如 α = 1/4 的中央 Bragg 面上，

V eff(0) = t22 2t1 (e−i4ky − 1).

当 t1 = 1、 t2 = 0.75、 kx = π/2 时， ky = π/4 处的中央直接间隔约为 0.9154759474； ky = π/2 处则严格接触。因此完整二维谱没有中央全局隙。

波函数型 IEB 的讨论仅提供背景。网站视频仍保留零耦合秩延拓；本讲解不替换该算法，也不把画面中的分支认证为波函数型 IEB。
